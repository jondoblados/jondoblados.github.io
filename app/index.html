Settings

The offline WEB translation is bundled with this app and always works, even offline. ESV, NIV and NLT are fetched live from each publisher using your own personal-use API key, because their license terms don't allow full offline storage of their text. Sign up for free keys at api.esv.org (ESV), api.bible/sign-up (NIV, via API.Bible), and api.nlt.to (NLT).

Sync via OneDrive / Google Drive

Export your notes and progress to a JSON file and save it in your Drive-synced folder. On another device, place the same file where the app can reach it, then import.

Your API keys are never included in a plain export. They stay only in this browser's local storage on this device. If you'd rather not re-type keys on every device, tick the box below to include them — encrypted with a passphrase only you know — so the file in your Drive folder still never has them in plain text.
